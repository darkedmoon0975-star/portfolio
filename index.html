01 — PROJECT

ATM Management System

About the Project

The ATM Management System is a Windows Forms desktop application created using C#.

The application simulates common ATM operations such as logging in, checking the account balance, depositing money, and withdrawing money.

This project demonstrates practical programming concepts such as variables, data types, numeric conversion, arithmetic operations, conditions, and button click events.
