My Project

ATM System

The ATM System is a desktop application that simulates basic ATM transactions. Users can log in, check their balance, deposit money, withdraw money, and log out.

The application was created to practice C# programming, Windows Forms, variables, data conversion, event handling, and basic program logic.

C# Windows Forms Visual Studio

ATM Features

🔐 Login

Users enter their account information and PIN to access the ATM system.

💰 Check Balance

Users can view their current account balance.

📥 Deposit

Users can enter an amount and add it to their current balance.

📤 Withdraw

Users can withdraw money from their account if sufficient funds are available.

🚪 Logout

Users can safely exit their ATM session.

About Me

I am an IT professional interested in application development and technology. I created this ATM System project to improve my programming skills and understand how a real-world transaction system works.
