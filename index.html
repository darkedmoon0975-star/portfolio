01 — PROJECT

My ATM Project

ATM Management System

The ATM Management System is a Windows Forms desktop application created using C#.

The purpose of this project is to simulate common ATM operations such as logging in, checking the account balance, depositing money, and withdrawing money.

The project also demonstrates how user input can be converted from text into numbers, processed using calculations, and displayed back to the application.

Technologies

C# Windows Forms Visual Studio
